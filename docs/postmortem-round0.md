## 根因

1. **排序按"分值/难度"而非"期望得分/分钟"**：a-hard 二轮重试（111min）挤掉了 c/f2 整块（公开矩阵早已证明 deepseek 能解 f2 七道、c 五道）。
2. **串行**：8c16G 沙箱只跑 1 路，吞吐砍半（BreachWeave 并发 3 容器）。
3. **模型档**：flash < pro < glm-5.2 < kimi-k3（公开 71.6%→79.7%→90.5%）。
4. **hint 从未使用**：二轮硬题 0 进展时，折分换 hint 期望值为正。
5. 托管链路（docker 镜像+网关改写）**从未实测**——8/17 最大运营风险。
