# learned/ — cross-run knowledge bundle

Generated by `scripts/learn.py <run_dir>` after a run. Bake into the image
(Dockerfile.overlay COPYs this dir to `/app/learned`) and the next run auto-seeds
its cross-challenge KB from here (`HEHUA_KB_SEED`), so each run starts smarter.

Files (not committed — they contain your own run's solve data):
- `knowledge.jsonl` — solved-case recipes (facts) per challenge family
- `priors.json`       — empirical solve-rate per family (overlays scheduler priors)
- `deadends.jsonl`    — failure notes per family (seed for dead-end injection)

Generate with: `python scripts/learn.py out` (or a specific run dir).
